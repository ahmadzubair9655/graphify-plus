§ 05 · Feature inventory

Every feature, honestly classified.

01

Adversarial audit

Seven probes that try to break the graph and report what they find. Edge deletion stability, confidence drift, rename sensitivity, articulation points, lonely INFERRED edges, modularity quality, centrality drift. Returns a weighted A–F grade with skipped-probe handling. Deterministic via seed.

production
tests34
cli✓
ci-gate✓ --fail-below
02

Graph diff for code review

Computes a structural diff between two graph snapshots. Detects added/removed nodes with per-change severity (LOW→CRITICAL), edge attribute changes, orphaned causal chains, god-node rank changes, contradiction count delta, and health-score delta when both reports are present. Outputs markdown, JSON, or text. Ships with a GitHub Action wrapper.

production
tests34
formatsmd · json · txt
github-action✓
03

Counterfactual simulation

Answers "what would break if I deleted this node?" by walking dependency relations, identifying broken causal chains, listing affected docs, and scoring severity. Supports delete, rename, deprecate, split, merge change types. Also reverses commits via temporal data.

production
tests5
change types5
04

Multi-agent verification

Run extraction with N different LLMs on the same content. Edges where ≥K models agree are tagged HIGH confidence. Disagreements are tagged DISPUTED with all model opinions attached. Defends against single-model systematic biases.

production
tests4
vote classesHIGH · DISPUTED · MINORITY
05

Self-healing proposals

Periodic background pass that scans for stale ambiguous flags, unresolved contradictions, confidence drift over re-extractions, orphaned nodes, and weak causal edges. Generates structured correction proposals with priority + suggested actions. Tracks confidence history in JSONL.

production
tests6
trigger types5
06

Multi-modal RAG retrieval

Combines text-graph retrieval with image retrieval. Indexes images, ranks them per-query by filename/path heuristics or CLIP-style embeddings (when caller supplies the encoders). Returns bundled {text_context, images} for the assistant.

prototype
heuristic path✓ works
clip pathhook only
07

Live graph daemon

File-watcher that detects corpus changes, debounces over a configurable window, triggers re-extraction, computes the resulting graph diff, and queues delta events. A real LSP server with subscription protocol is left to a future revision.

prototype
polling✓ works
lsp protocolnot impl.
08

Federation coordinator

Member registry + query routing for cross-team graph queries. Each team runs their own graphify-plus instance; the coordinator routes by capability or namespace and merges responses. HTTP transport, auth, and discovery are pluggable.

prototype
routing✓ works
auth/discoveryhook only
09

Local extraction

Replaces remote LLM calls with on-device models. Similarity edges via sentence-transformers (works if installed). Relation extraction via fine-tuned small models — the interface is defined, the actual fine-tuning is left to the user.

stub

relation extractionnot impl.
10

Personal knowledge layer

Ingest sources beyond code: notes folder, shell history, browser history, Slack, meetings. Notes & shell history are real implementations. Browser/Slack/meetings are stubs that document the integration paths needed.
