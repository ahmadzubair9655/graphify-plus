# graphify-plus examples

Runnable scripts that demonstrate the daemon surface end-to-end. Each
script is self-contained — pick whichever one matches the question
you're trying to answer.

| Script | Question it answers |
|---|---|
| `walkthrough.sh` | What does a typical session look like? |
| `find_untested.py` | Which functions in my repo have no tests? |
| `pr_review_comment.py` | What should I post as a PR review comment? |
| `onboard_new_dev.py` | How do I introduce someone to this codebase? |
| `audit_security.sh` | What CVEs and SAST findings reach my code? |
| `gpl_query.py` | How do I write a custom graph query? |

Each script assumes you've already run `gp init --repo <yourrepo>` once.
